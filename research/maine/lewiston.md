## Fee facts (schedule as adopted, effective 2013-07-01)

The schedule prices by project type. The rows this seed models:

| Type | Fee |
| --- | --- |
| Single family — New construction/Additions | **$25 base + $0.25/sf** |
| Single family — Accessory structure | $25 base + $0.07/sf |
| Single family — Renovation < $2,500 | **$25 base + $5.00 per $1,000 value** |
| Multi-family — New construction/Additions | $25 base + $0.30/sf |
| Multi-family — Renovations | **$25 base + $5.00 per $1,000 value** |
| Mobile home — New or Used | $25 base + $0.35/sf (per floor) |
| Mobile home — Additions | $25 base + $7.00 per $1,000 value |

**Belated Fee:** "The customary permit fee shall double where work commences
prior to the issuance of the appropriate permits."
**Reimbursement:** 75% refunded within six months if no work commenced; City
retains 25%.

(The extracted PDF's layout scrambles the rows — the label column and fee
column mispair across pages — but the schedule's row set is unambiguous when
read against the City Council agenda packet of 2021-03-09 that reproduces the
same schedule in clean layout: the valuation rows are the renovation rows for
single- and multi-family, at $25 base + $5.00 per $1,000.)

## Reading decisions

1. **Renovations price by value; new construction by area.** The schedule
   deliberately splits the two: renovations (single- and multi-family) read
   $25 base + $5.00 per $1,000 of value; new construction/additions read
   per-square-foot rates. The calculator models the valuation rows (the
   calculator's basis is valuation) and documents the area rows in prose.
2. **The doubling belated fee** is a penalty on unpermitted work, named in
   prose, not a component.
